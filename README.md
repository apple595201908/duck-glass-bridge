# 《鴨鴨踩玻璃橋》（首頁：鴨鴨跳格子）
### Mobile-First 視覺空間序列記憶挑戰手遊

> 「玩家永遠應該看得清楚，但不一定記得住。」  
> 專為現代手機瀏覽器打造的工作記憶（Working Memory）與空間序列認知遊戲。

---

## 🎮 遊戲核心定位與設計哲學

本遊戲是一款純正的**「視覺空間序列記憶遊戲」**，核心玩法：
**看清順序 ➔ 記住位置 ➔ 按照相同順序點擊。**

### ⚠️ 核心認知原則：絕非速讀/手速遊戲
- **禁止壓縮展示速度作為主要難度**：遊戲嚴格禁止將格子亮燈時間縮短至玩家來不及看清的程度（如 200~300ms）。
- **底線保護（Hard Clamp）**：單格亮起有效展示時間**不得低於 700ms**，並具備至少 **120~150ms** 的熄滅視覺間隔。
- **清晰數字指引**：題目播放期間，亮起格子中央同步顯示清晰數字（`1`、`2`、`3`……），以「淡入（80ms）➔ 清楚停留（約600ms）➔ 淡出（80ms）」的節奏呈現，確保玩家辨識無障礙。
- **真正難度來源**：
  1. **Sequence Length（序列長度）**：記憶負載從 3 步循序提升至 10 步以上。
  2. **Board Complexity（棋盤維度）**：從 2×2（4格）➔ 3×3（9格）➔ 4×4（16格）。
  3. 優先級：**序列長度 ＞ 棋盤大小 ＞＞＞ 播放速度**。

## 🎨 美術與視覺風格 (可愛 × 微恐怖深淵)

1. **原創 Q 版小黃鴨主角**：
   - 大頭比例、圓滾滾毛茸身軀、俏皮呆毛、短翅膀與短腳、橘黃圓潤小鴨嘴、橘色腳掌。
   - 雙重水汪汪高光的超萌黑眼；在答錯時眼球睜大驚恐、嘴巴張成圓形「O」字。
   - 支援 6 種動畫狀態：`Idle`（呼吸起伏）、`Prepare`（起跳蓄力）、`Jump`（拋物線伸展）、`Landing`（落地微震與擠壓）、`Surprised`（驚愕失色）、`Falling`（失去重心旋轉墜入黑洞）。
2. **透明晶瑩強化玻璃格**：
   - 具備半透明折射、斜角邊緣高光、內凹陰影與深色深淵透視感。
   - 題目亮起時釋放高飽和明亮水晶青光與大號白色立體數字。
   - 答錯時：落地微震 ➔ 第一道衝擊主裂紋 ➔ 100ms 蛛網狀深度碎裂紋 ➔ 整塊玻璃爆碎成多邊形破片 ➔ 鴨鴨跌入虛空！
3. **老式電子紅色七段顯示器 (7-Segment LED)**：
   - HUD 的 `LEVEL`、`SCORE`、`BEST` 採用具備底層未點亮暗紅段（`#120305`）與點亮發光鮮紅段（`#ff2a3b` + Glow）的復古工業儀器風格。
4. **深淵背景空間**：
   - 墨黑與暗石青漸層，搭配中央深淵冷色柔霧與極簡暗調，營造刺激專注的臨場感。

## 🔊 音效系統 (Web Audio API 程序合成)

無須載入外部龐大音檔，100% 由瀏覽器 AudioContext 即時即算：
- **題目亮燈音（`playTileTone`）**：587.33Hz D5 溫潤水滴鐘琴音，**全格固定同頻**，避免給予聽覺位置線索。
- **跳躍音（`playJump`）**：240Hz ➔ 420Hz Q 彈滑音。
- **落地音（`playLanding`）**：低通濾波微震鈍擊反饋。
- **玻璃裂痕音（`playGlassCrack`）**：高頻石英碎裂微爆音。
- **玻璃碎裂爆破音（`playGlassShatter`）**：帶通濾波白噪音碎片衝擊波 + 不諧和音頻群。
- **掉落深淵音（`playFalling`）**：卡通滑音笛深淵俯衝降音（460Hz ➔ 65Hz）。
- **過關音（`playLevelClear`）**：明快琶音旋律（C5 - E5 - G5 - C6）。
- **觸覺震動（Haptic）**：支援手機端輕量微震反饋。

## 🏗️ 模組化技術架構

```
duck-glass-bridge/
├── index.html                   # Mobile-First 網頁進入點 (100dvh, safe-area-inset)
├── package.json                 # 專案相依配置 (Vite + TypeScript)
├── tsconfig.json                # TypeScript 編譯設定 (Bundler 模組解析)
├── vite.config.ts               # Vite 打包配置 (支援 GitHub Pages 相對路徑)
└── src/
    ├── main.ts                  # 應用主流程與場景切換器
    ├── style.css                # 核心樣式（GPU 加速、玻璃擬真、7-Seg LED）
    ├── types.ts                 # 狀態機、關卡配置、動畫狀態介面定義
    ├── config/
    │   └── difficultyConfig.ts  # 嚴格難度表 (700ms 下限保護、平滑回退、無盡演算法)
    ├── core/
    │   ├── GameStateManager.ts  # 狀態機 (MENU / SHOW_SEQ / PLAYER_INPUT 等)
    │   ├── SequenceGenerator.ts # 序列生成器 (保證 sequence[i] !== sequence[i-1])
    │   ├── ScoreManager.ts      # 計分器 (序列獎勵、棋盤加乘、微量速度獎勵限制)
    │   ├── StorageManager.ts    # 本地最高紀錄 (localStorage + 安全 Fallback)
    │   ├── DifficultyManager.ts # 關卡配置管理與晉級判斷
    │   └── AudioManager.ts      # Web Audio API 合成音效與觸覺震動管理器
    ├── components/
    │   ├── DuckController.ts    # 原創 Q 版小黃鴨 (SVG、跳躍拋物線、深淵墜落動畫)
    │   ├── GlassTile.ts         # 強化玻璃格 (發光、階梯數字、破裂紋、粉碎)
    │   └── Board.ts             # 2x2 / 3x3 / 4x4 動態網格棋盤與 Pointerdown 零延遲
    ├── ui/
    │   └── SevenSegmentDisplay.ts # 紅色 7 段 LED 數位顯示器渲染器
    ├── effects/
    │   └── GlassShatterEffect.ts # 60FPS 預製多邊形破片物理與鏡頭晃動
    └── scenes/
        ├── MenuScene.ts         # 首頁「鴨鴨跳格子」（展示台、最佳紀錄、立即開玩）
        ├── TutorialScene.ts     # 3~5 秒極速互動導引
        └── GameScene.ts         # 核心遊戲場景、HUD、暫停防窺視窗、結算畫面
```

## 🚀 本機執行與建置方式

```bash
# 1. 進入專案目錄
cd "C:\Users\user\Desktop\鴨鴨踩玻璃橋"

# 2. 安裝相依套件 (若未安裝)
npm install

# 3. 啟動開發伺服器
npm run dev

# 4. 建置正式發行版本
npm run build

# 5. 預覽發行版本
npm run preview
```

## 📱 手機相容性與體驗驗證

- ✅ **Mobile-First 版型**：以 `100dvh` 及 CSS safe-area 徹底適配 iPhone Dynamic Island、瀏海及 Android 手勢條。
- ✅ **觸控優化**：全面採用 `pointerdown` 事件，杜絕 iOS Safari 300ms 點擊延遲；停用雙擊縮放與 Pull-to-refresh。
- ✅ **極致輕量**：打包後 HTML+CSS+JS 總體積小於 60KB，手機可在 100ms 內極速開啟，無須登入即可暢玩！
